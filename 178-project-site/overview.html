Project Motivation

Aerodynamic analysis is an important component of aircraft design, whether it is used for designing lifting surfaces, control surfaces, propulsion systems, or GNC algorithms. This analysis usually requires computationally expensive computational fluid dynamics (CFD) simulations that must be run over a large range of potential operating points. This can quickly become impractical for engineering problems that require a lot of analysis to be done both often and quickly.

A proposed solution to this problem that has seen growing attention in recent years is to develop ML surrogate models trained on sparse data sweeps conducted using CFD software. These models can then be used to predict aerodynamic data for conditions that have not been directly simulated. Surrogate models have the advantage of requiring less compute power and running much faster, allowing for rapid design iteration or use in GNC algorithms.

Given that our group members all work in aerospace or aerospace-adjacent fields, we wanted to see if we could use the knowledge we learned in this E178 class to create a surrogate model for the aerodynamic properties of a flying wing and apply it to an aircraft control problem.

Background

What is surrogate modeling?

A surrogate model is a machine learning model that has been trained on a set of data generated by CFD, FEA, or experiment that can be used to predict parameters that would otherwise be obtain utilzing these methods. The model serves as a faster approximation of a more expensive simulation or experiment. In training this model you reduce the number of simulations or experiments needed to just the amount needed to train an acccurate model, reducing time and cost. This however does impose a fundamental limitation on the use of surrogate models as they are oly valuable if the cost of training and running the model is less than just using the silulation or experiment to generate all of the needed data. This means that surrogate modeling is only useful in applications where very large amounts of data need to be generated.

expensive simulation / experiment data → regression model → fast approximate prediction

The key tradeoff is speed versus fidelity. A useful surrogate model should be much faster than the original analysis tool while still preserving the trends that matter for whatever the model is being used for. These models have other drawbacks as well the main one being their geometry dependence. surrogate models are only as accurate as the data they were trained on meaning tat a model developed for one airfoil would not necessaily be an accurate model for a different one. Despite these limitations surrogate modeling still find much use in the areas of control and design iteration shere many different parameters need to be generaterd quicly and often.

Connect to Our Project

How We Plan To Use Surrogate Modeling

This project applies surrogate modeling to the simulation of a flying wing aircraft, predicting its aerodynamic coefficets for any position in 3D space. The original aerodynamic data is generated from sparse OpenVSP sweeps along a combination of angle of attack and yaw angle and along the principle axes of the control surface deflection angles.rom this data we use regression to train a surrogate that maps angle of attack, yaw angle, and control surface deflections to the six aerodynamic coefficients experienced by the aircraft.

Input: [α, β, δS, δD] → MLP regression model → Output: [CL, CD, CY, Cl, Cn, Cm]

With this model generated we then apply the surrogate to an aircraft control problem. Once the surrogate is trained and can predict aerodynamic coefficients quickly, those coefficients can be converted into forces and moments inside a flight dynamics simulation. These moments can them be used to predict required control deflections to maintain a specified trajectory in an model prediictive control (MPC) framwork, serving as the finla demonstration of the sucess and acuracy of our model.

Step 1
Generate sparse data Collect aerodynamic coefficient samples across selected flight and control conditions.
Step 2
Train regressors Train a set of regression models that map flight angles and surface deflections to aerodynamic coefficients.
Step 3
Select best surrogate Compare the regression models and select the one that most accuratly captures the relationship between these angles and coefficents.
Step 4
Use in aircraft controller Use the selected model as the dynamics solver in an MPC framework to demonstrate the abilities and usefulness of our model.
