Process

Creating, training, and evaluating machine learning models for our use case.

With a data-set of around 4000 vectors we have multiple different approaches of creating a model that accounts for parameters that are on non principal axes. This project will require the use of multiple different machine learning models. The process will follow these 6 steps.

  1. Load the data from the master sheets.
  2. Scramble the ordered data from the mastersheet into a new shuffled csv file.
  3. Normalize the data.
  4. Organize and fit our data into input sequences and output values.
  5. Build train and evaluate the three model.
  6. Compare the models and choose the best performer.

Step 1: Loading our data from the master sheet.

Using the Pandas library we can simply load our off axis data and basis data. We cut off any un-needed columns to reduce our data frame to the following inputs and outputs.

Inputs

  1. α -> Vertical Attitude
  2. β -> Horizontal Attitude
  3. ΔS -> Elevon Combined Angle
  4. ΔD -> Elevon Angle Differential

Outputs

  1. CD -> Drag Coeff.
  2. CL -> Lift Coeff.
  3. CY -> Side Force Coeff.
  4. Cl -> Roll Coeff.
  5. Cn -> Yaw Coeff.
  6. Cm -> Moment Coeff.
